# qt5ct dependencies

Stowing this package links one file, the generated Wisteria Dusk color scheme at `~/.config/qt5ct/colors/wisteria-dusk.conf`. It is the Qt 5 twin of the `qt6ct` package, generated by the same `theming/targets/qtct.py`. `~/.config/qt5ct/qt5ct.conf` is deliberately not in this package: qt5ct rewrites it whenever a setting changes in the GUI. Install the following first.

**Always stow this package with `--no-folding`:**

```sh
stow -n -v --no-folding qt5ct   # dry run
stow -v --no-folding qt5ct
stow -R --no-folding qt5ct      # restow
```

Without it, on a machine where `~/.config/qt5ct` doesn't exist yet, stow would link the whole directory into this repo, and qt5ct would write `qt5ct.conf` into the repo.

## Required

| Dependency | Why | Install docs |
|---|---|---|
| qt5ct | Loads color schemes from `~/.config/qt5ct/colors/`. The scheme lists 21 colors per group (Qt 5 has no `Accent` role). Tested on qt5ct 1.9 with Qt 5.15 | https://sourceforge.net/projects/qt5ct/ |
| `QT_QPA_PLATFORMTHEME` set to `qt6ct` or `qt5ct` | Without it Qt apps ignore qt5ct. The `hyprland` package sets `qt6ct` in `modules/env.lua`; Qt 5 apps have no `qt6ct` plugin and still end up on qt5ct with it (tested with VLC), so no change is needed | https://wiki.archlinux.org/title/Uniform_look_for_Qt_and_GTK_applications |

Install commands (copied from the linked docs for convenience; if they disagree, the linked docs win):

```sh
# Arch / CachyOS
sudo pacman -S --needed qt5ct

# Debian / Ubuntu
sudo apt install qt5ct

# Fedora
sudo dnf install qt5ct
```

## Optional

None.

## Verify

```sh
command -v qt5ct >/dev/null && echo "qt5ct ok" || echo "qt5ct MISSING"
case "$QT_QPA_PLATFORMTHEME" in qt5ct|qt6ct) echo "platform theme ok" ;; *) echo "QT_QPA_PLATFORMTHEME not qt5ct/qt6ct" ;; esac
```

## After stowing

Open `qt5ct`, go to Appearance, tick "Custom" under Palette, and choose `wisteria-dusk` from the color scheme list. Set the icon theme to Breeze Dark in the Icon Theme tab to match the GTK and qt6ct setup. Restart Qt 5 apps (e.g. VLC) to pick it up.
