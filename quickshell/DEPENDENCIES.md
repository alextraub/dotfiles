# quickshell dependencies

Stowing this package links `~/.config/quickshell` as a single folded symlink to the repo folder, so new or renamed files need no restow. It is the status bar, started by the `hyprland` package's `modules/autostarts.lua`. Install the following first.

Layout of `.config/quickshell/`:

| Path | What |
|---|---|
| `shell.qml` | Entry point, one `StatusBar` per screen |
| `config/` | `Theme` (sizes, fonts, timings) and the generated `Colors` singleton (`import qs.config`) |
| `services/` | Singletons wrapping system state: `Audio`, `Clock`, `Power` (`import qs.services`) |
| `components/` | Reusable widgets; icons and `icons/iconSets.js` (icon selectors) live in `components/icons/` |
| `modules/` | Bar layouts built from components, e.g. `modules/status_bar/` |
| `util.js`, `assert.js` | Plain JS helpers, imported by relative path (`import "../util.js" as Util`) |

`config/colors.json` and `config/Colors.qml` (the `Colors` singleton that loads the JSON, with the same colors as defaults, plus the accent and `tint()`) are generated by `python3 theming/generate.py` from `theming/palette.json` (see `theming/targets/quickshell.py`). Edit those, not the generated files.

## Required

| Dependency | Why | Install docs |
|---|---|---|
| Quickshell | Runs `shell.qml`, its default config at `~/.config/quickshell`. Tested on 0.3.1 | https://quickshell.org/docs/guide/install-setup/ |
| PipeWire | `services/Audio.qml` reads and sets the default sink's volume through `Quickshell.Services.Pipewire` | https://docs.pipewire.org/ |
| JetBrainsMono Nerd Font | `Theme.font` in `config/Theme.qml`, the bar's text | https://www.nerdfonts.com/font-downloads |
| Material Symbols Rounded (variable) | `Theme.iconFont` in `config/Theme.qml`. Icons are ligature names from `components/icons/iconSets.js`, and `Theme.iconAxes` needs the variable font for its FILL/wght axes | https://fonts.google.com/icons |

Install commands (copied from the linked docs for convenience; if they disagree, the linked docs win):

```sh
# Arch / CachyOS
sudo pacman -S --needed quickshell pipewire ttf-jetbrains-mono-nerd ttf-material-symbols-variable

# Fedora
sudo dnf copr enable errornointernet/quickshell
sudo dnf install quickshell

# Debian / Ubuntu: no official package. Build from source:
# https://git.outfoxxed.me/outfoxxed/quickshell
```

## Optional

| Dependency | Why | Install docs |
|---|---|---|
| qmlls | QML language server for editing `shell.qml`; run it as `qmlls -E`. Quickshell writes a machine-specific `.qmlls.ini` next to `shell.qml` for it, which lands in the repo folder and is kept out of git by `.gitignore` | https://quickshell.org/docs/guide/install-setup/ |

## Verify

```sh
command -v qs >/dev/null && echo "quickshell ok" || echo "quickshell MISSING"
command -v pipewire >/dev/null && echo "pipewire ok" || echo "pipewire MISSING"
for f in "JetBrainsMono Nerd Font" "Material Symbols Rounded"; do fc-list | grep -q "$f" && echo "$f ok" || echo "$f MISSING"; done
```

## After stowing

`~/.config/quickshell` must be a symlink (`ls -ld ~/.config/quickshell`). If it is a real directory holding per-file links (e.g. because Quickshell had already written `.qmlls.ini` there), new files will not appear. Refold it:

```sh
rm -f ~/.config/quickshell/.qmlls.ini
stow -D quickshell && rmdir ~/.config/quickshell && stow -v quickshell
```

Hyprland starts it at login. To start it by hand, run `qs -d`. It reloads automatically when a file changes, but a newly added singleton (a `pragma Singleton` file) is only picked up on a restart:

```sh
qs kill && qs -d
```
